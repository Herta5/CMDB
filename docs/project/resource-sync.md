# CMDB 云资源同步规范

## 文档职责

本文档定义接入源同步频率、并发边界、任务结果、失联恢复和物理删除条件。任何云平台采集器都必须遵循同一套同步核心规则。

## 触发与并发

- 接入源默认每一小时自动同步一次。
- 有权限的用户可以手工触发同步。
- 同一接入源不得并发运行多个同步任务；自动任务与手工任务遵守同一并发限制。
- 不同接入源可以并行同步。

## 采集结果处理

- 单类资源采集失败时，不得对该资源类型执行失联判定。
- 部分资源类型失败时，任务标记为“部分成功”；成功类型仍正常入库，失败类型保留同步前状态。
- 接入源认证失败时，不得更新任何资源的失联状态。
- 采集失败、认证失败或任务未执行不得作为确认资源缺失或推进物理删除的依据。

## 资源生命周期

- 已入库资源在对应资源类型的一次成功采集中首次未出现在返回结果中时，标记为“已失联”并记录失联开始时间。
- 已失联资源在物理删除前重新出现时，恢复原记录及正常状态，并保留失联和恢复审计。
- 资源连续失联满 24 小时后，必须再次完成该资源类型的成功采集并确认资源仍未出现，才允许物理删除。
- 物理删除不得仅由定时器或失联开始时间触发，必须具有满 24 小时后的成功采集确认。

## 任务统计与敏感信息

- 同步任务必须分别记录各资源类型的新增、更新、恢复、失联、删除和失败统计。
- 任务状态和统计不得因单类资源失败而丢弃成功类型的处理结果。
- 任务日志、错误和审计内容必须过滤密码、令牌、AccessKey、主加密密钥及完整密文。

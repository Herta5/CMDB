# CMDB 前端体验规范

## 文档职责

本文档定义 CMDB 控制台的信息架构、资源列表体验、状态覆盖、视觉风格和首期适配范围。

## 信息架构

- UI 采用现代云管理控制台风格，使用左侧分组导航和顶部项目切换。
- 阿里云和 AWS 分别作为一级功能模块，但共享统一资源核心数据。
- 项目切换必须同步更新当前页面的数据归属，不得残留或展示前一项目的数据。

## 资源页面

- 资源列表优先保证信息密度和可检索性。
- 资源列表支持筛选、排序、分页和列配置。
- 页面必须覆盖加载、空数据、失败、无权限和资源失联状态。
- 资源失联状态必须清晰可辨，但不得遮挡资源身份和最近有效属性。

## 视觉与适配

- 使用浅色、低饱和的中性色体系。
- 云平台品牌色只用于平台识别，不使用大面积装饰性渐变。
- 首期适配常见桌面分辨率并保证平板可用，不要求手机端专项适配。

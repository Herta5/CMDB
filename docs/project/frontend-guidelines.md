# CMDB 前端体验规范

## 文档职责

本文档定义 CMDB 控制台的信息架构、资源列表体验、状态覆盖、视觉风格和首期适配范围。

## 信息架构

- UI 采用现代云管理控制台风格，使用左侧分组导航和顶部项目切换。
- 左侧导航最上方必须提供独立“首页”入口，其后分为“资产”和“管理”两组。“资产”组提供服务器/计算实例、数据库和负载均衡三类资产入口；“管理”组统一包含业务项目、云同步管理和审计日志，且仅系统管理员可见用户管理入口。
- “首页”与资产、管理分组下的功能入口使用一致的导航状态：未选中时均为灰色图标和文字、透明背景，当前页面入口统一使用浅蓝色背景和加粗文字；首页不得因为是独立入口而始终显示为蓝色链接。
- 控制台必须使用统一的“云同步管理”入口管理阿里云和 AWS 接入源、连接测试和同步任务。该入口不得将两个采集器混同为一个平台模块，阿里云和 AWS 的凭证格式与采集边界仍按各自模块处理。
- 顶部项目切换是所有项目级页面的全局数据边界。切换项目后，页面必须清除前一项目的列表数据、详情、筛选结果和待提交操作，并用新项目上下文重新向服务端查询；不得短暂展示、保留或提交前一项目的数据。
- 系统管理员的项目切换器必须提供“所有项目”选项，也可以选择单个项目。在“所有项目”上下文中，系统管理员只能跨项目只读查询资产、接入源、同步任务和项目审计，且每条记录必须明确显示所属项目；所有创建、编辑、启停、连接测试、手工同步、重试、删除等项目级写入或操作前必须选择一个具体项目，不能把“所有项目”作为操作目标。
- 普通用户的项目切换器只允许显示其当前成员关系已授权的项目；不得通过浏览器缓存、路由参数或搜索结果暴露其他项目名称、数据或可选项。项目管理员和项目成员均不得使用“所有项目”上下文。
- 项目停用后，前端必须保留该项目的历史资料、资产、任务和审计的只读入口，并禁用或隐藏新的连接测试、手工同步、重试和自动任务创建等不可执行操作。具备接入源管理权限的角色仍可编辑已有接入源配置，以便在重新启用前修复配置；系统管理员仍可维护项目状态。前端限制只改善体验，最终规则以 [security.md](security.md) 的服务端实时授权为准。

## 用户标识

- 所有用户列表、选择器、详情、确认提示、项目成员和审计页面都必须使用用户名标识用户，不得显示或要求输入用户数字 ID。
- 显示名称可以作为用户名旁的辅助资料展示，但用户名必须始终可见，并作为选择、筛选和操作用户的实际值。
- 用户名输入必须在提交前校验为 1 至 64 个字符且只包含 ASCII 字母、数字和下划线；格式错误时使用中文提示说明允许的字符。
- 前端路由、接口参数、应用状态和浏览器持久化存储不得依赖用户数字 ID；涉及用户的请求一律传递用户名。

## 资源页面体验摘要

本节仅说明资源页体验目标；资源列表的列、筛选、排序、服务端分页、列配置和失联资产规则以 [资源列表](#资源列表) 为准，加载、空数据、失败、无权限和提交中状态以 [管理操作与页面状态](#管理操作与页面状态) 为准。

## 视觉与适配摘要

本节仅说明首期视觉与适配目标；浅色低饱和、品牌识别、桌面与平板范围及可达性规则以 [视觉、响应式与可达性](#视觉响应式与可达性) 为准。

## 页面职责

- **登录页**：提供用户名和密码输入、提交中状态及统一的中文失败提示；不得依据用户不存在、密码错误或账号已停用呈现可用于枚举身份的差异提示。登录完成后仅保存完成会话所需的最小信息，不得在页面状态或浏览器持久化存储保存密码、云凭证或用户数字 ID。
- **首页**：作为登录后的默认入口，按顶部当前项目汇总服务器、数据库和负载均衡三类正常资产总数，明确说明统计不包含已失联资产，并提供对应资产列表入口。服务器统计包含 ECS 与 EC2，数据库统计包含两平台 RDS，负载均衡统计包含 SLB、CLB、ALB、NLB、GWLB；系统管理员选择“所有项目”时汇总全部可访问项目。统计必须使用服务端返回的总条数，不得通过加载固定数量资源明细推算；项目切换时必须立即清空旧统计并阻止迟到响应覆盖新项目。
- **服务器/计算实例、数据库、负载均衡页**：分别提供 ECS/EC2、阿里云 RDS/AWS RDS、SLB/CLB/ALB/NLB/GWLB 的只读资产列表和详情入口。负载均衡页固定查询 `slb`、`clb`、`alb`、`nlb`、`gwlb`，并按官方大写缩写展示类型；同名类型仍通过云平台列区分，旧 `elb` 不得作为查询或展示标签。三类页面共享本规范的资源列表交互；类型专属字段只在对应页面展示。服务器列表将实例类型、vCPU、内存 GiB 和磁盘总容量 GiB 分为独立列，磁盘只显示如 `140 GiB` 的总容量，不附带磁盘数量；接口保留每块云盘的 ID、系统盘/数据盘、类型、容量 GiB、设备名和加密状态。数据库列表将实例类型、vCPU、内存、数据库引擎、引擎版本和存储容量分为独立列，列表不显示存储类型；无法可靠确定的字段统一显示 `—`，不得显示为 `0`、“未知”或给占位符附加单位，也不得把托管存储显示为逐盘明细。数据库同时展示完整访问地址，负载均衡展示网络类型与端点。页面不得提供人工修改云平台原始属性、云端状态或资产状态的操作。
- **业务项目页**：项目列表用于选择、查看和管理业务项目；项目详情用于展示基本资料、负责人、成员和项目内入口。系统管理员可以创建、编辑、启停和删除项目，项目管理员及项目成员只能查看所属项目；成员管理操作仅对系统管理员和所属项目的项目管理员可见。
- **用户管理页**：仅系统管理员可见，用于查询公开用户资料、创建用户、编辑资料、启停、删除和配置角色。所有用户选择、展示、筛选、路由和提交必须使用用户名，不得显示、接收、存储或要求填写用户数字 ID。
- **云同步管理页**：在当前具体项目内管理阿里云和 AWS 接入源，展示接入源启用状态、脱敏凭证配置状态、最近与下次同步时间，并提供编辑、连接测试、立即同步、任务历史和可重试任务入口。阿里云来源的探测和任务结果完整展示 ECS、RDS、SLB、ALB、NLB、GWLB，AWS 完整展示 EC2、RDS、CLB、ALB、NLB、GWLB。系统管理员可管理任意具体项目，项目管理员仅可管理所属项目，项目成员只能查看脱敏后的接入源和同步结果。页面不得展示稳定云账号标识或身份验证时间。
- **审计日志页**：系统管理员可在“所有项目”或具体项目上下文查询全局和项目审计；项目管理员只能查询所属项目审计；项目成员不得看到入口、路由内容或任何审计数据。列表的操作人必须以显示名称为主信息、用户名为下方辅助信息；系统任务仍明确标记为“系统任务”。每条记录必须在列表中直接显示带文字和图形线索的结果：已提交的普通管理操作显示“成功”；同步任务显示“成功”“部分成功”或“失败”；连接测试根据可达与失败资源类型显示同样三种结果；缺少可靠结果的历史数据显示“状态未知”，不得猜测为成功。每次同步在列表中只占一行，`source.synced` 的对象列显示操作发生时保存的接入源名称快照，绝不以数据库 ID 冒充名称；详情按变化动作和资源类型展示数量及全部云端唯一 ID，无变化时明确显示“本次同步未产生资源变化”。审计筛选使用用户名和公开对象标识，资源类型按官方大写缩写展示（SLB、CLB、ALB、NLB、GWLB），不得将当前负载均衡显示为旧 `ELB`；展示内容不得泄露内部用户 ID、凭证或原始云错误。
- 前端路由守卫、导航隐藏和按钮禁用必须按当前角色与项目上下文改善体验；它们不得代替服务端的身份、项目成员关系和角色校验。服务端拒绝后，页面必须停止展示受保护数据并呈现统一的无权限状态。

## 资源列表

- 资源列表必须优先保证信息密度和可检索性，并至少展示资源名称、云端唯一 ID、所属项目（“所有项目”上下文必显）、接入源、云平台、资源类型、地域或可用区、云端状态、CMDB 资产状态和最近发现时间。资源名称为空时，云端唯一 ID 仍必须可见。
- 三类资源列表将宽模糊搜索框、筛选、列设置和刷新列表按此顺序收纳在同一个列表卡片顶部，页面标题区不重复放置刷新操作。三类搜索都匹配完整查询范围内的资源名称和云端唯一 ID；服务器与数据库另匹配实例类型，服务器另匹配内网 IP、公网 IP，数据库与负载均衡另匹配完整访问地址，不额外显示重复的搜索范围说明。后端必须先搜索再计算总数与分页，禁止仅搜索当前页。精确筛选默认折叠：服务器提供云平台、接入源、类型、地域、云端状态和资产状态，数据库提供云平台、接入源、数据库引擎、地域、云端状态和资产状态，负载均衡提供云平台、接入源、类型、网络类型、地域、云端状态和资产状态；只有用户明确应用的条件以可单项移除的标签展示，并可全部清除。
- 三类资源列表固定按资源名称升序请求且不提供排序切换、排序箭头或排序说明，每页 20 条，可切换 20、50、100 条。服务器列表独立展示实例类型、vCPU、内存 GiB、磁盘总容量 GiB、地域、完整内网 IP、完整公网 IP、云端状态、资产状态和格式为 `YYYY-MM-DD HH:mm:ss` 的最近发现时间；列表地域不得混入可用区，多个 IP 必须分行显示，并继承表格正文的字体与字号。
- 数据库列表默认按“资产、项目（仅所有项目）、来源、类型、实例类型、vCPU、内存、数据库引擎、引擎版本、存储容量、地域、访问地址、云端状态、资产状态、最近发现时间”排列。地域只显示地域；多个访问地址分行显示完整域名和端口，列表不显示解析 IP；最近发现时间格式为 `YYYY-MM-DD HH:mm:ss`。无法确定的实例类型、规格、引擎、版本、容量或地址统一显示 `—`。
- 负载均衡列表默认按“资产、项目（仅所有项目）、来源、类型、网络类型、地域、访问地址、云端状态、资产状态、最近发现时间”排列。类型使用 SLB、CLB、ALB、NLB、GWLB 官方大写缩写；`internet`、`internet-facing` 显示为“公网”，`intranet`、`internal` 显示为“私网”。地域只显示地域；多个访问地址分行显示完整域名或 IP 与端口，列表不显示协议和解析 IP；最近发现时间格式为 `YYYY-MM-DD HH:mm:ss`，无法确定的值统一显示 `—`。
- 云端状态以页面中文语义统一展示和筛选：`running`、`active`、`available` 归为“运行中”，`stopped`、`inactive` 归为“已停止”，`failed`、`CreateFailed` 归为“失败”；其他已识别状态仍使用对应中文标签。筛选必须匹配同一中文语义下的跨平台原始值，不能让页面显示为某状态却无法被该状态筛中。
- 点击服务器资源名称必须从右侧打开只读详情抽屉，并保留列表搜索、筛选、分页和滚动上下文。详情按“基本信息、实例配置、网络信息、磁盘明细、状态与时间”分组，展示名称、实例 ID、项目、来源、平台、类型、地域、可用区、实例类型、vCPU、内存、全部内外网 IP、逐盘明细、云端状态、资产状态、首次发现、最近发现和失联开始时间；实例 ID 与每个 IP 提供单项复制。详情不得展示云平台原始属性快照。
- 点击数据库资源名称必须从右侧打开只读详情抽屉，并保留列表上下文。详情按“基本信息、实例配置、数据库信息、访问地址、状态与时间”分组；除列表字段外补充可用区、存储类型、访问协议、解析 IP、首次发现和失联开始时间。实例 ID 与每个完整访问地址提供复制，详情不得展示云平台原始属性快照。
- 点击负载均衡资源名称必须从右侧打开只读详情抽屉，并保留列表上下文。详情按“基本信息、网络信息、状态与时间”分组；除列表字段外补充可用区、端口、协议、解析 IP、首次发现和失联开始时间。实例 ID 与每个完整访问地址提供复制，详情不得展示云平台原始属性快照。
- 云平台、资源类型和 CMDB 资产状态必须可组合筛选。三类专属资产页由页面类别预设对应类型范围，默认范围不作为生效筛选标签重复展示；用户明确选择具体资源类型后必须展示可移除标签。筛选变化必须由服务端重新查询，且清除已有结果后回到第一页。
- 三类资产查询在首次加载、清除筛选和重试时，未填写的可选筛选必须从 HTTP 查询参数中省略，不得发送 `provider=` 等空值导致接口契约拒绝。具体项目与“所有项目”使用同一参数整理规则，保留已填写的筛选、类别类型范围、排序及分页参数，不修改页面持有的筛选对象。
- 资源列表不提供前端排序交互。三类资源列表每次查询固定使用资源名称升序，服务端必须追加资源身份“接入源 + 资源类型 + 云端唯一 ID”的固定次级排序，确保翻页与刷新时顺序稳定。
- 资源列表必须使用服务端分页，明确显示当前页、每页数量和总条数；不得依赖一次性加载全部资源后在浏览器中伪分页。筛选、项目上下文或每页数量改变后必须回到第一页；翻页、刷新和失败重试均必须保留当前有效筛选条件及固定排序。
- 资源列表必须提供列配置，允许用户显示或隐藏可选列、调整显示顺序并恢复默认配置。服务器页的来源、类型、实例类型和地域可以隐藏；资产、所属项目（出现时）、vCPU、内存、磁盘、内网 IP、公网 IP、云端状态、资产状态和最近发现时间不得隐藏。列配置可以按用户名、页面类型和项目上下文持久化，但不得使用或保存用户数字 ID、凭证、令牌或资源敏感原始属性。
- 数据库页的来源、类型、实例类型、引擎版本和地域可以隐藏；资产、所属项目（出现时）、vCPU、内存、数据库引擎、存储容量、访问地址、云端状态、资产状态和最近发现时间不得隐藏。
- 负载均衡页的来源、类型、网络类型和地域可以隐藏；资产、所属项目（出现时）、访问地址、云端状态、资产状态和最近发现时间不得隐藏。
- “已失联”必须以文字状态和非颜色标记清晰展示，并保留资源名称、云端唯一 ID、接入源、最近发现时间及最近一次有效的可展示属性；不得把失联资源伪装成已删除，也不得因为采集失败、认证失败或任务未执行而在页面上擅自标记失联。

## 管理操作与页面状态

- 新建接入源时必须提交对应平台的完整凭证；提交期间显示“正在验证云账号身份”，只有后端完成联网识别和保存后才能显示成功。编辑页不得从接口或本地状态回填明文、密文、凭证片段或云账号标识；凭证字段留空表示保留原凭证，用户显式提交完整新凭证才表示整体替换并重新确认仍为原账号。页面只可显示“已安全配置”等脱敏状态。
- 新建与编辑的每次弹窗和提交必须绑定独立上下文。项目切换或关闭后重开时，旧提交的成功、失败及清理回调不得关闭新弹窗、清空新输入或解除新提交状态；旧请求只负责清理自身持有的凭证。创建和编辑后的服务端刷新只能写回仍有效的发起上下文，刷新期间切换项目也不得把旧数据或旧失败提示写入新项目。
- 同项目轮询只更新读取顺序，不作废仍有效的新建或编辑提交；提交成功或失败后仍须刷新服务端事实，失败时保留安全中文提示。
- 同一项目内已发出的多次新建或编辑提交不得因启动先后相互作废；每次完成都须独立刷新，最终列表包含所有已提交的服务端事实。刷新响应交错时仅最新启动的读取可写回列表；共享提交提示按提交结果的完成顺序归属，较早结果的迟到刷新不得覆盖较晚结果的提示。项目切换和弹窗会话隔离规则保持不变。
- 连接测试必须是独立操作，页面只展示各资源类型可达/不可达及中文安全摘要；它不得被表示为同步结果，不得更新资源列表、最近同步时间或资产状态。连接测试、同步错误和任务详情不得展示云平台原始响应、堆栈、密码、令牌、AccessKey、主加密密钥或完整密文。
- “立即同步”提交成功后，页面必须将新任务呈现为“排队”（`queued`），并轮询其状态至终态。任务状态只使用“排队”“运行中”“成功”“部分成功”“失败”；终态必须展示按资源类型的安全统计与安全摘要。只有“失败”或“部分成功”的任务提供“重试”操作，重试创建新任务而不覆盖原任务记录。
- 表单必须在提交前校验必填项、格式、数值范围和当前项目上下文，并为每个可纠正字段提供中文错误提示。提交期间必须禁用重复提交和相互冲突操作；服务端成功或失败后均必须以服务端重新查询的结果刷新页面，不得只依据客户端推测更新列表、状态或权限。
- 云账号冲突、替换凭证身份不一致、删除依赖冲突和云身份识别失败必须显示稳定中文说明。失败后重新查询服务端事实，不得保留伪成功状态；说明不得披露其他项目、接入源、云账号标识、内部 ID 或云平台原始错误。
- 删除项目、删除接入源、删除用户、停用用户或项目、替换凭证等危险操作必须展示操作对象、影响和不可逆或权限影响的中文确认提示；确认后仍须等待服务端结果，取消不得发送请求。
- 每个数据页及其关键操作必须覆盖以下状态：首次加载与刷新加载、空数据、请求失败、无权限和提交中。加载状态不得将旧项目数据当作新项目结果；空数据必须说明当前上下文与可执行的下一步；失败状态必须提供安全中文摘要和重试入口；无权限状态不得保留受保护详情；提交中必须说明正在执行的操作并避免重复提交。

## 视觉、响应式与可达性

- 页面必须使用浅色、低饱和的中性色体系；云平台品牌色只用于阿里云和 AWS 的平台识别，不得作为大面积装饰性渐变或唯一状态传达方式。
- 首期必须在常见桌面分辨率下完整可用；平板尺寸允许表格横向滚动并保持表头、主要操作与筛选可访问；不要求手机端专项布局或交互适配。
- 表单控件、筛选器、图标按钮、项目切换器和危险操作确认必须提供可见标签或等效的中文语义标签。键盘用户必须能够按逻辑顺序到达导航、项目切换、筛选、表格、分页、弹窗确认和关闭控件，并始终看到清晰焦点。
- 成功、失败、运行中、已失联、停用和无权限等状态必须同时使用中文文本、图标或形状等非颜色线索；错误提示必须与对应控件或区域建立可感知关联，动态加载和提交结果必须以不会打断当前操作的方式提示。
- 页面空状态、失败提示、确认提示和无权限说明必须使用准确的中文业务文案，不得把接口路径、内部 ID、原始异常、凭证或其他敏感信息直接展示给用户。

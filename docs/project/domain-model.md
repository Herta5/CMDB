# CMDB 领域模型与资产状态

## 文档职责

本文档定义业务项目、云账号、云资源和访问端点的数据归属、唯一身份及资产状态语义。资源状态的具体流转条件由 `resource-sync.md` 定义。

## 数据归属边界

- 业务项目是系统最高级的管理、数据归属和权限隔离边界。
- 一个云账号或云租户只能归属于一个业务项目。
- 接入源同步的云资源、访问端点和资源关系必须继承接入源所属的业务项目，不得跨项目归属。

## 用户身份与引用

- 用户名是用户在 CMDB 中全局唯一且不可修改的对外标识，长度为 1 至 64 个字符，只能包含 ASCII 字母、数字和下划线，必须符合 `^[A-Za-z0-9_]+$`。
- 页面以及公开 API 的请求体、响应体、路径参数和查询参数凡是引用用户，都必须使用用户名，不得暴露、接收或要求填写用户数字 ID。
- 项目负责人、项目成员和审计记录等业务对象对外引用用户时必须使用用户名；用户类审计对象的资源标识和审计详情也必须使用用户名。
- 用户数字 ID 仅可作为数据库主键、外键和后端内部关联字段，后端负责在用户名与内部 ID 之间转换，不得把该实现细节传递给客户端。
- 显示名称可以作为用户资料和辅助文案保留，但不得代替用户名承担身份引用、接口传参或权限判断职责。

## 云资源身份

- 云资源以“接入源 + 资源类型 + 云端唯一 ID”作为唯一身份。
- 同一资源的重复同步必须更新原记录，不得创建重复资产。
- 已失联资源重新出现时必须恢复原记录，不得以新资源重新入库。

## 资源属性

- 云平台返回的原始属性由同步模块维护，CMDB 页面和普通业务接口不得手工修改。
- ECS 和 EC2 保存网卡上的内网 IP 与公网 IP。
- RDS 和负载均衡保存原始域名、端口及最近一次成功解析得到的 IP。
- 域名解析得到的动态 IP 只用于最近解析结果，不得作为固定资产属性。

## 资产状态

- 正常：资源最近一次符合条件的成功采集结果中仍然存在。
- 已失联：已入库资源在对应资源类型的一次成功采集中未出现在返回结果中，并已记录失联开始时间。
- 已删除：资源满足 `resource-sync.md` 的删除确认条件后被物理删除。
- 物理删除资源时可以同步删除访问端点和资源关系，但审计日志必须保留。

# CMDB 领域模型与资产状态

## 文档职责

本文档定义用户、业务项目、接入源、同步任务、云资源、访问端点和审计日志的领域关系、数据归属及状态语义。项目级授权规则由 [security.md](security.md) 定义，任务执行和资源生命周期的具体流转条件由 [resource-sync.md](resource-sync.md) 定义。

## 核心对象关系

- **用户**是可登录并被授权的主体。用户通过项目成员关系加入零个或多个业务项目；系统管理员是全局权限例外，无需加入项目即可跨项目管理和查看数据。
- **业务项目**是普通用户的最高级数据归属和权限隔离边界。项目可选关联一名负责人；负责人只是项目资料字段，不自动创建项目成员关系，也不自动获得项目权限。
- **项目成员关系**连接一名用户和一个业务项目，并记录其项目角色。同一用户在同一项目只能有一条成员关系；成员关系以项目为边界，不得复用于其他项目。
- **接入源**归属于且只归属于一个业务项目，并声明一个云平台和一个云账号或云租户。相同云平台的同一云账号或云租户不得在不同项目重复接入；接入源不得跨项目迁移。
- **同步任务**针对一个接入源的一次采集执行记录，因而继承该接入源的业务项目归属；任务结果、统计和审计均不得写入其他项目。
- **云资源**由一个接入源同步，必须继承其业务项目归属。资源以“接入源 + 资源类型 + 云端唯一 ID”作为唯一身份；同一身份的重复同步更新原记录，已失联资源重新出现时恢复原记录。
- **访问端点**是云资源的附属连接信息，随资源继承项目归属；不得独立归属其他项目或手工改写云端采集属性。
- **审计日志**记录重要操作和状态变化，可关联项目、操作人及业务对象。业务项目、接入源或资源被删除后，相关审计日志仍必须长期保留以支持历史追溯。

## 管理对象约束

### 用户

- 用户名是用户在 CMDB 中全局唯一且不可修改的对外标识，长度为 1 至 64 个字符，只能包含 ASCII 字母、数字和下划线，必须符合 `^[A-Za-z0-9_]+$`。
- 页面以及公开 API 的请求体、响应体、路径参数和查询参数凡是引用用户，都必须使用用户名，不得暴露、接收或要求填写用户数字 ID。
- 项目负责人、项目成员和审计记录等业务对象对外引用用户时必须使用用户名；用户类审计对象的资源标识和审计详情也必须使用用户名。
- 用户数字 ID 仅可作为数据库主键、外键和后端内部关联字段，后端负责在用户名与内部 ID 之间转换，不得把该实现细节传递给客户端。
- 显示名称可以作为用户资料和辅助文案保留，但不得代替用户名承担身份引用、接口传参或权限判断职责。

### 业务项目与成员

- 项目编码全局唯一，创建后不可修改；它用于稳定识别项目，项目名称和描述可以按权限更新。
- 项目状态只有“启用”和“停用”。停用表示项目不再作为可运行的业务范围；具体可执行操作及其权限校验由 [security.md](security.md) 规定。
- 项目负责人可以为空，负责人被删除后负责人字段置空；负责人不是成员角色的替代物，也不得据此推导项目权限。
- 项目成员角色只有项目管理员（`project_admin`）和项目成员（`member`）两种。系统管理员是全局角色，不是第三种项目成员角色。
- 一个云账号或云租户只能归属于一个业务项目；即使凭证、显示名称或接入源记录不同，也不得绕过这一归属限制重复接入。

## 云资源模型

### 公共资产字段

ECS、EC2、RDS、SLB 和 ELB 在各自独立的资产模型中保存，避免把平台或类型专属属性混入其他资源；资源列表和查询接口以统一资产视图提供共同筛选和展示。每个资产至少包含以下公共字段：

- 所属业务项目、接入源、云平台、资源类型和云端唯一 ID；这些字段共同确定归属与资源身份，云平台原始属性只能由同步模块维护。
- 资源名称、地域、可用区和云端状态；云端状态保留云平台返回的运行或生命周期语义。
- CMDB 资产状态、首次发现时间、最近发现时间、失联开始时间、创建时间和更新时间；各时间字段的语义见“状态与时间语义”。
- 原始属性快照；它用于保留云端返回的扩展信息，不是页面或普通业务接口的手工编辑区。

### 类型专属字段

- **ECS / EC2（计算实例）**：保存网卡上的内网 IP 与公网 IP。
- **RDS（数据库实例）**：保存数据库引擎、引擎版本和访问端点。
- **SLB / ELB（负载均衡）**：保存网络类型和访问端点。
- **访问端点**：每项端点记录类型（例如内网或公网）、地址、端口、协议及最近一次成功解析得到的 IP。地址可以是 IP 或域名；域名的最近解析 IP 是动态观测结果，不得作为固定资产身份或固定属性。

## 状态与时间语义

- **云端状态**与**资产状态**是两个独立维度：云端状态由云平台返回并由同步模块维护；资产状态由 CMDB 根据成功采集时的可见性维护。云端状态变化不等同于资产失联，资产失联也不推断云端状态。
- 在库资产状态只有“正常”和“已失联”。“正常”表示资源在对应资源类型最近一次符合条件的成功采集中存在；“已失联”表示已入库资源在该类型成功采集中未出现，并已记录失联开始时间。
- “已删除”不是在库资产状态枚举，而是满足 [resource-sync.md](resource-sync.md) 删除确认条件后的物理删除结果。物理删除前必须满足失联时长和成功采集确认要求；采集失败、认证失败或任务未执行不得标记失联或触发物理删除。
- 首次发现时间记录资产首次成功入库的时刻；最近发现时间只在成功采集再次发现该资产时刷新；失联开始时间只在资产转为已失联时写入，并在恢复正常时清空。
- 同一资源的稳定业务字段、原始属性和端点未变化时，只刷新最近发现时间，不得虚增更新时间、更新统计或无意义审计。端点解析结果等**易变观测**属性的变化只更新相应观测快照和最近发现时间，不得虚增业务字段更新统计。
- 资源从已失联恢复时，保留同一资源记录，恢复为正常并清空失联开始时间；失联与恢复均应留下审计轨迹。

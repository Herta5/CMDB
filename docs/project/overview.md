# CMDB 产品定位与首期范围

## 文档职责

本文档定义 CMDB 的产品定位、首期交付范围和云平台模块边界。涉及产品名称、能力范围或模块拆分的修改必须以本文档为准。

## 产品定位

- 项目名称统一为 **CMDB**，文档、页面标题、接口说明和部署配置不得使用其他产品名称。
- CMDB 是面向公有云的资源配置管理平台。
- CMDB 面向因多云资产分散、归属不清、状态不可追溯和权限边界不明确而难以管理的组织，提供以业务项目为边界的统一资源视图和管理能力。
- 产品能力围绕业务项目、云账号、云资源、同步任务、权限、资产状态和审计展开；业务项目是数据归属和普通用户权限隔离的最高边界。
- CMDB 不承担云资源编排、费用管理、监控告警、工单处理或向云端写回资源属性的职责。

## 目标用户与角色

- **系统管理员**：CMDB 的最高权限角色，可以跨项目查看和管理数据及项目审计记录，无需预先加入项目；负责初始化管理员、用户和业务项目的全局管理。
- **项目管理员**：在已加入的业务项目内负责项目成员、接入源和项目资产的管理，并可查询所属项目的项目审计记录、组织项目内的同步与审计核查。
- **项目成员**：在已加入的业务项目内只读查询项目资料、接入源、资产、访问端点和同步结果；不得查询项目审计记录或越过项目边界访问其他项目数据。

## 核心业务闭环

CMDB 的标准闭环为：**初始化管理员 → 创建用户和项目 → 授权 → 创建并测试接入源 → 同步 → 查询资产 → 审计**。各环节必须以业务项目为归属边界；项目内权限、同步规则和审计细则分别由 [security.md](security.md)、[resource-sync.md](resource-sync.md) 和 [domain-model.md](domain-model.md) 定义。

## 首期范围

- 阿里云模块负责 ECS、RDS 和 SLB。
- AWS 模块负责 EC2、RDS 和 ELB。
- 控制台统一使用“云同步管理”入口管理阿里云和 AWS 接入源；该入口不改变两个平台采集模块各自独立的边界。
- 阿里云和 AWS 实现在同一个 CMDB 服务中，不拆分为独立部署服务。
- 两个平台模块保持清晰边界，并通过统一接口接入共享资源核心。
- 业务项目、权限、接入源抽象、同步任务、云资源、访问端点、资产状态和审计属于公共核心，不得在平台模块中重复实现；平台模块只负责各自的凭证格式和云 API 采集。

## 不在首期范围

- 除阿里云 ECS、RDS、SLB 及 AWS EC2、RDS、ELB 外的云平台和资源类型。
- 云资源编排、费用管理、监控告警、工单处理，以及向云端写回资源属性。
- 将阿里云或 AWS 采集能力拆分为独立部署服务。

## 关键术语

- **业务项目**：CMDB 中最高级的数据归属和普通用户权限隔离单元；一个云账号或云租户只能归属于一个业务项目。
- **接入源**：业务项目接入某个云账号或云租户的配置载体，包含受保护的凭证及其平台信息，是同步任务和云资源的来源。
- **云资源**：由接入源同步的云端对象，以“接入源 + 资源类型 + 云端唯一 ID”作为唯一身份，且必须继承接入源所属业务项目。
- **云端状态**：云平台返回的资源运行或生命周期状态，由同步模块采集和维护，不等同于 CMDB 的资产状态。
- **资产状态**：CMDB 对资源同步可见性和生命周期的管理状态，用于表达资源是否正常、失联、恢复或满足删除条件。
- **访问端点**：云资源对外或对内提供访问所需的地址、端口、协议等连接信息，由公共核心统一管理。
- **同步任务**：针对一个接入源发起的资源采集执行记录，用于记录触发、执行结果、统计和审计；失败、认证失败或未执行不得据此将资源标记失联或物理删除。

## 范围变更

新增云平台、资源类型或独立部署单元，以及改变本文件定义的产品目标、角色、模块边界或不在首期范围的能力，均属于产品范围变更；实施前必须获得用户确认并同步更新本文档。

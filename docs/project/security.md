# CMDB 安全、权限与审计规范

## 文档职责

本文档定义项目级访问控制、云平台凭证保护、敏感信息输出和审计保留要求。

## 项目权限隔离

- 所有项目级接口必须校验当前用户的项目成员身份和项目角色。
- 禁止跨项目读取或修改业务项目、接入源、云资源、访问端点、同步任务和审计数据。
- 无权限访问项目数据时，响应不得泄露目标项目、接入源或资源是否存在。

## 身份标识暴露边界

- JWT 的载荷可被客户端解码，不属于后端内部数据；JWT 必须使用用户名标识当前用户，不得携带用户数字 ID。
- 后端必须根据 JWT 中的用户名读取当前有效用户，再使用数据库内部 ID 完成项目成员关系、负责人和审计等关联查询；不得信任客户端提交的内部用户 ID。
- 公开 API、页面、浏览器状态、持久化存储、用户可见错误信息和审计内容不得暴露用户数字 ID，也不得以用户数字 ID 作为用户操作入口。
- 用户管理、项目负责人和项目成员接口必须以用户名作为用户标识；审计查询以操作人用户名筛选，用户类审计对象及详情中的用户引用也必须使用用户名。
- 数据库可以保留用户数字主键及外键，但这些字段仅用于服务端内部的数据完整性和关联效率。

## 凭证与敏感信息

- 云平台凭证必须使用部署环境提供的 `CMDB_ENCRYPTION_KEY` 加密后存储。
- 密码、令牌、AccessKey、主加密密钥及完整密文不得写入日志、审计内容、接口响应、测试快照或代码仓库。
- API 和页面只显示完成当前操作所必需的凭证脱敏信息。
- 测试必须使用虚构凭证或模拟数据，不得依赖或记录真实云账号凭证。

## 审计

- 权限、接入源、同步任务和资产状态的重要变更必须保留可追溯审计。
- 云资源物理删除后，其审计日志仍必须保留。
- 审计内容必须在持久化前过滤敏感信息，不得依赖展示层临时脱敏。

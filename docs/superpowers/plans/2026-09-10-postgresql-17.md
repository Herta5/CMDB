# PostgreSQL 17 替换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 CMDB 从 MySQL 8.4 完整替换为全新 PostgreSQL 17，采用管理员与应用双账号，并在验收后永久删除旧 MySQL 数据卷。

**Architecture:** PostgreSQL 容器以 `postgres` 管理员初始化空库，再创建最小权限 `cmdb` 登录角色；单一 PostgreSQL 初始化结构创建业务表、约束和中文注释。Go 应用改用 GORM PostgreSQL 驱动和通用重复键错误转换，Docker Compose 对外开放 5432，并以严格验收门槛控制旧 MySQL 数据卷删除。

**Tech Stack:** Go 1.25.1、Gin、GORM、PostgreSQL 17、Vue 3、TypeScript、Docker Compose。

**Spec:** `docs/superpowers/specs/2026-09-10-postgresql-17-design.md`

## Global Constraints

- 使用全新空 PostgreSQL 数据库，不迁移任何 MySQL 数据。
- `postgres` 管理员与受限 `cmdb` 应用账号使用不同部署密码。
- PostgreSQL 对外开放 `5432`，CMDB 继续开放 `80`。
- 所有新增或修改代码必须包含准确、必要的中文注释。
- PostgreSQL 完整验收前不得删除 MySQL 数据卷；验收后删除且不提供旧数据回退。
- 云同步、项目权限、三类资产表、24 小时失联清理和审计规则保持不变。
